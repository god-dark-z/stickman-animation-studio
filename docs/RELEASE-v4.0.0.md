# v4.0.0 — Bangla, built in


Bangla as a first-class production language, a skill written for models of every size, and a
repository that tells the truth about itself.

### Added

**Bangla, built in (one install, no extra steps)**
- `engine/lang/` — language packs as data: `en/` and `bn/` with voice catalogs, caption layout,
  measured speech rates and word budgets. Adding a language is now a data task.
- `scripts/resolve_language.ts` — deterministic trigger with **59 tests** over English, Bangla
  script, Banglish, negations, flag precedence and topic false positives ("a story about Bangla
  literature" stays English). `--lang` reaches every stage and the story JSON metadata.
- `scripts/bn_normalize.py` — Unicode cleanup, spoken numbers (South-Asian grouping, years as
  উনিশশো নব্বই), decimals, percentages, ordinals, currency, times, dates, phone runs, units,
  pronunciation pass, sentence-aware chunking, grapheme-safe cuts. **44 tests.**
- `engine/lang/bn/pronunciation.json` — **392 entries**, generated by a checked-in script.
- `scripts/tts_bn.py` — voice fallback (gender before accent), chunked synthesis on an exact byte
  clock, and **forced alignment** when a voice returns no boundaries: measured **mean 107 ms,
  max 147 ms** on real audio vs 306 ms for a proportional split.
- `scripts/qa_bangla.py` + `scripts/qa_gloss.ts` — the Bangla text gate (one script per video,
  every shot glossed) and **bidirectional gloss faithfulness** (the Bangla and its English gloss
  must carry the same claims).
- `engine/lang/bn/intent-glossary.json` — **108 intents** across all 14 categories, sharing the
  English requirement vocabulary; includes the idioms that are easy to misread.
- `engine/lang/bn/commonsense-battery.json` — **49 micro-stories** across 14 categories.
- `engine/lang/bn/sync-lexicon.json` — 66 canonical claims with Bangla and English cues.
- **Bundled Bengali fonts** (Noto Sans Bengali, Hind Siliguri, Baloo Da 2 — 329 KB, OFL) with
  `document.fonts` blocking before the first frame; `scripts/qa_glyphs.py` proves every on-screen
  character has a glyph; Bangla digits in inserts.
- `scripts/choose_voice.ts` — automatic narrator choice from topic tone and genre, with a written
  score and reason; character voices with a distinctness check. **41 tests.**
- 9 Bengali props with measured anchors: rickshaw, tea stall, kettle, glass tea, wooden bench,
  jute sack, jhalmuri, market board, rickshaw hood.
- `references/12-bangla-voice-and-script.md` — register, measured budgets, 22 good/bad sentence
  pairs, voice direction, on-screen rules.

**Skill excellence**
- `SKILL.md` rewritten as a director's manual: hard rules, capability probe, the 13-stage table
  (what each gate *proves*), per-stage direction with self-checks, a 14-row failure playbook, a
  countable quality bar.
- `references/13-format-library.md` — 10 story formats with beats, shot grammar, endings and
  worked English + Bangla examples; a hook bank; emotional arcs; a repetition guard.
- `references/14-model-tiers.md` — small / standard / max, with the same gates for all.
- `docs/agents/` — playbooks for 10 products plus chat-only, each honest about what it can do.
- `scripts/eval.ts` + `evals/REPORT.md` — **332/332** measured checks across both batteries, the
  resolver, voice choice, the normalizer, timing, typecheck, skill lint and every test story's gates.
  Per-model rows accepted only with a source; nothing inferred.
- `scripts/skill_lint.ts` — frontmatter, link/path resolution, JSON examples, stray files,
  reference-map completeness, no placeholders.
- `scripts/qa_rubric.ts` — the craft rubric, finally executable: six axes per shot scored from gate
  evidence, written to `craft-rubric.md`, a pipeline stage.

### Changed
- `requirements.txt`: `edge-tts==7.0.2` → **`7.2.1`**. The old pin could not even run the engine's
  own `boundary="WordBoundary"` call (support starts at 7.2.0) — a clean install would have failed
  every narration, English included.
- `on: "chair"` now resolves to the **nearest** matching prop, not the first: two characters on
  "chair" were both drawn on the same seat.
- README rebuilt as a short landing page; `README.bn.md` written by hand; `docs/gallery.md`.

### Fixed
- The glossary's phrase normalizer deleted Bangla entirely (`[^a-z0-9]`), then (after the first
  fix) stripped the combining marks that Bangla vowel signs are — `চেয়ারে` became `চ য র`. Bangla
  matching was impossible and silent.
- `পড়ছে` no longer means "reading" on its own: in "বৃষ্টি পড়ছে" it means *falling*.
- `অনেক` no longer means "many" on its own: "অনেক ঠান্ডা" means *very* cold.
- Bangla insert cards no longer collide with the caption band; years in a Bangla chart render in
  Bangla digits.
- `bench_wood`'s seat was 38 px too low — the geometry gate caught it on a real render.

### Notes
- English defaults are frozen by tests; the demo's gates are byte-identical to the pre-V4 baseline.
- The craft rubric's floor (no shot below 3) is enforced; the average of 4 is reported, and the
  shipped demo honestly sits at 3.81 with the missing points named.

## Verify it yourself

```bash
git clone https://github.com/god-dark-z/stickman-animation-studio && cd stickman-animation-studio/engine
npm install && pip install -r requirements.txt
npm run doctor
npm test && npm run eval && python scripts/test_all.py
npx tsx scripts/studio.ts stories/why-phone-gets-hot.json --tier standard     # English
npx tsx scripts/studio.ts stories/tests/bangla-tea-stall.json --tier standard # Bangla
```

## Honest limits

- Only the ZCode run was executed end to end here; other agent installs are documented, not verified.
- Per-model eval rows are empty (they need paid APIs, which this project forbids).
- The craft rubric enforces a 3/5 floor; the demo averages 3.81 against an aspirational 4. The
  missing points are named in `docs/dev/v4/VERIFY-H-studio.md`, not hidden.
