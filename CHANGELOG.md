# Changelog

## 4.0.0 — 2026-11-26

Bangla as a first-class production language, a skill written for models of every size, and a
repository that tells the truth about itself.

### Added

**Bangla, built in (one install, no extra steps)**
- `engine/lang/` — language packs as data: `en/` and `bn/` with voice catalogs, caption layout,
  measured speech rates and word budgets. Adding a language is now a data task.
- `scripts/resolve_language.ts` — deterministic trigger with **59 tests** over English, Bangla
  script, Banglish, negations, flag precedence and topic false positives ("a story about Bangla
  literature" stays English). `--lang` reaches every stage and the story JSON metadata.
- `scripts/bn_normalize.py` — Unicode cleanup, spoken numbers (South-Asian grouping, years as
  উনিশশো নব্বই), decimals, percentages, ordinals, currency, times, dates, phone runs, units,
  pronunciation pass, sentence-aware chunking, grapheme-safe cuts. **44 tests.**
- `engine/lang/bn/pronunciation.json` — **392 entries**, generated by a checked-in script.
- `scripts/tts_bn.py` — voice fallback (gender before accent), chunked synthesis on an exact byte
  clock, and **forced alignment** when a voice returns no boundaries: measured **mean 107 ms,
  max 147 ms** on real audio vs 306 ms for a proportional split.
- `scripts/qa_bangla.py` + `scripts/qa_gloss.ts` — the Bangla text gate (one script per video,
  every shot glossed) and **bidirectional gloss faithfulness** (the Bangla and its English gloss
  must carry the same claims).
- `engine/lang/bn/intent-glossary.json` — **108 intents** across all 14 categories, sharing the
  English requirement vocabulary; includes the idioms that are easy to misread.
- `engine/lang/bn/commonsense-battery.json` — **49 micro-stories** across 14 categories.
- `engine/lang/bn/sync-lexicon.json` — 66 canonical claims with Bangla and English cues.
- **Bundled Bengali fonts** (Noto Sans Bengali, Hind Siliguri, Baloo Da 2 — 329 KB, OFL) with
  `document.fonts` blocking before the first frame; `scripts/qa_glyphs.py` proves every on-screen
  character has a glyph; Bangla digits in inserts.
- `scripts/choose_voice.ts` — automatic narrator choice from topic tone and genre, with a written
  score and reason; character voices with a distinctness check. **41 tests.**
- 9 Bengali props with measured anchors: rickshaw, tea stall, kettle, glass tea, wooden bench,
  jute sack, jhalmuri, market board, rickshaw hood.
- `references/12-bangla-voice-and-script.md` — register, measured budgets, 22 good/bad sentence
  pairs, voice direction, on-screen rules.

**Skill excellence**
- `SKILL.md` rewritten as a director's manual: hard rules, capability probe, the 13-stage table
  (what each gate *proves*), per-stage direction with self-checks, a 14-row failure playbook, a
  countable quality bar.
- `references/13-format-library.md` — 10 story formats with beats, shot grammar, endings and
  worked English + Bangla examples; a hook bank; emotional arcs; a repetition guard.
- `references/14-model-tiers.md` — small / standard / max, with the same gates for all.
- `docs/agents/` — playbooks for 10 products plus chat-only, each honest about what it can do.
- `scripts/eval.ts` + `evals/REPORT.md` — **332/332** measured checks across both batteries, the
  resolver, voice choice, the normalizer, timing, typecheck, skill lint and every test story's gates.
  Per-model rows accepted only with a source; nothing inferred.
- `scripts/skill_lint.ts` — frontmatter, link/path resolution, JSON examples, stray files,
  reference-map completeness, no placeholders.
- `scripts/qa_rubric.ts` — the craft rubric, finally executable: six axes per shot scored from gate
  evidence, written to `craft-rubric.md`, a pipeline stage.

### Changed
- `requirements.txt`: `edge-tts==7.0.2` → **`7.2.1`**. The old pin could not even run the engine's
  own `boundary="WordBoundary"` call (support starts at 7.2.0) — a clean install would have failed
  every narration, English included.
- `on: "chair"` now resolves to the **nearest** matching prop, not the first: two characters on
  "chair" were both drawn on the same seat.
- README rebuilt as a short landing page; `README.bn.md` written by hand; `docs/gallery.md`.

### Fixed
- The glossary's phrase normalizer deleted Bangla entirely (`[^a-z0-9]`), then (after the first
  fix) stripped the combining marks that Bangla vowel signs are — `চেয়ারে` became `চ য র`. Bangla
  matching was impossible and silent.
- `পড়ছে` no longer means "reading" on its own: in "বৃষ্টি পড়ছে" it means *falling*.
- `অনেক` no longer means "many" on its own: "অনেক ঠান্ডা" means *very* cold.
- Bangla insert cards no longer collide with the caption band; years in a Bangla chart render in
  Bangla digits.
- `bench_wood`'s seat was 38 px too low — the geometry gate caught it on a real render.

### Notes
- English defaults are frozen by tests; the demo's gates are byte-identical to the pre-V4 baseline.
- The craft rubric's floor (no shot below 3) is enforced; the average of 4 is reported, and the
  shipped demo honestly sits at 3.81 with the missing points named.

## 3.1.0 — 2026-11-24

Commonsense: the film draws what the sentence implies, not only what the JSON says.

### Added
- **`engine/data/intent-glossary.json`** — 61 intents across 14 categories (posture, location,
  containment, held, in-use, state, time-weather, motion, count-scale, people, emotion, negation,
  cause, abstract), each with a GOOD and a BAD rendering. `qa_commonsense.ts` matches a shot's
  narration against these and fails when the canonical picture is missing.
- **Scene Spec / Director's Brief** — `templates/scene-spec.md`, `src/commonsense/spec.ts`,
  `scripts/spec_check.ts`. One block per shot: place, who, **what supports each body**, implied
  props, relations, world state, emotion, camera purpose, negations. `where.otherRoom` requires a
  written `transitionPlan`.
- **Numeric relation graph** — `src/commonsense/relations.ts`: `on`, `in`, `inside`, `under`,
  `behind`, `in_front_of`, `beside`, `holding`, `facing`, `looking_at`, `touching`, `inside_room`
  are tested against the resolved scene; `wearing`/`part_of` are reported as visual-only.
- **The commonsense battery** — `engine/data/commonsense-battery.json` + `scripts/battery.ts`:
  61 micro-stories, each with a plan, an expected picture and a machine-checkable requirement.
  Runs in seconds and writes `out/battery/report.md` (per-category pass rates).
- Spec files for the two contact fixtures: `stories/tests/{chair-office,bed-sleep}.spec.json`.
- `references/11-commonsense-intents.md`, `templates/scene-spec.md`, SKILL.md §0.4 with the
  decision table, the six self-check questions and the ambiguity/metaphor protocol.
- `intentExempt` on the story: a reasoned, per-shot exemption for a metaphor, printed as a WARN.
- 5 new unit tests (27 total): glossary accept/reject, relation graph, spec support, exemption.

### Fixed
- `qa_geometry` treated **every** action as a placement action, so `hold`/`use`/`face`/`pointAt`/
  `react`/`handOver` were rejected as "action without `on` prop". Only `sitOn`, `lieOn`, `sleepOn`
  and `standAt` resolve anchors now.
- "The seat was empty" was hard-coded to `chair`; a bench failed. `noActorOnAny` + `propsAny`.
- The chair and bed fixtures narrated a window that was never drawn; a pass of the spec gate found
  it, and `bed-sleep` shot 4 faced the camera instead of the window. Both corrected.
- `use-cooking` matched the metaphor "his phone goes from cool to cooking"; phrases tightened to
  literal cooking, with the exemption mechanism for genuine metaphors.
- Studio gains a `commonsense` stage (after `geometry`); `npm run qa` now runs the glossary and the
  battery.

## 3.0.0 — 2026-11-24

The release that makes the picture provable.

### Added
- **Semantic action layer.** `action: "sitOn" | "lieOn" | "sleepOn" | "standAt"` plus `on` on an
  actor. The engine resolves the pose, root position, draw order and contact from a prop's anchors,
  so an agent no longer hand-writes coordinates for interaction shots (`references/05`).
- **`engine/src/scene/anchors.ts`** — contact surfaces (`seat`, `mattress`, `pillow`, `top`) and
  drawing extents for furniture, vehicles and screens.
- **`engine/src/scene/layout.ts`** — pure scene geometry shared by the renderer and the gates.
- **`qa_geometry.ts`** — the scene-graph gate: contact, sink/float, scale, layering, face
  occlusion, framing, facing, seated→standing continuity. Exit 1 on any error.
- **`qa_timing.py`** — per-word timing audit against the audio's energy envelope.
- **`qa_video.py`** — container/resolution/fps/duration/dead-frame gate.
- **`qa_visual_report.py`** — contact sheet + per-shot claim checklist (`visual-review.md`), and a
  reader for recorded verdicts. Replaces the never-shipped `agentvision` instruction.
- **`studio.ts` + `npm run studio`** — one state-machine entry point with
  `--tier draft|standard|studio`, `--resume`, `--from <stage>`, per-stage status, state in
  `stories/<slug>/.state.json`, log in `out/<slug>/run.log`.
- **`doctor`** (`npm run doctor`, `python scripts/doctor.py`) — PASS/WARN/FAIL with the fix command,
  including a real software-WebGL frame probe (`doctor_gl.ts`).
- **`validate.ts`** — cheap schema/cast/prop/location validation before any expensive stage.
- **`paths.ts`** — `resolvePaths`/`resolveStory`, `--engine <dir>` supported by every script.
- **`engine/requirements.txt`** — pinned Python dependencies.
- **9 story fixtures** in `engine/stories/tests/` (seating, sleeping, kitchen, driving, dialogue,
  science, history-with-quotes, chart + day→night, one-shot edge case).
- **8 new unit tests** (22 total), including numeric contact regression tests for the chair and bed.
- `docs/dev/{AUDIT,PLAN-*,VERIFY-*,DECISIONS,BLOCKERS}.md`, `docs/TROUBLESHOOTING.md`,
  `docs/showcase/` (seated / sleeping stills, demo contact sheet).

### Fixed
- A character described as sleeping is now **in the bed** (head on pillow, body on the mattress,
  blanket over the torso) instead of lying on the floor beside it.
- A seated character's hip now sits **on** the seat surface; `sit` no longer lowered the body 58 px
  into the chair.
- Lying shadow is horizontal (was a vertical smear).
- The bed drawing was widened to 440 units so a lying body fits between the boards.
- `agentvision` references removed from `SKILL.md` and `templates/sync-map.md`.
- Clone URL placeholder (`<you>`) fixed in `README.md` and `install/INSTALL.md`.
- Stray `agentvision-render.png` removed from the repository root.
- Windows `UnicodeEncodeError` in every Python gate (stdout is now UTF-8).
- Concurrency is capped by free RAM as well as core count; 3D shots render at 2 workers.
- Word-count guidance corrected from "190–210 words ≈ 60–75 s" to the measured **≈3.8–4.0 w/s**
  (≈50–57 s for 190–210 words) at the default `+22%`.
- `npm run studio` now runs the orchestrator; the Remotion preview is `npm run remotion`.

### Changed
- `BUILD` character metrics moved into `scene/layout.ts` (single source of truth).
- Background set dressing of the same type at the same position is replaced by the shot's own prop,
  so you can sit on "the" bed without drawing two.
- Geometry-gate verdicts: contact/layering/occlusion/framing-of-head are errors; a contact surface
  behind the caption band is a warning.

### Migration
- **Existing story JSON keeps working unchanged.** Every new field defaults to the old behaviour
  (`action: "none"`, `underBlanket: false`, `inside: false`).
- A story that used `pose: "sit"`/`"lie"` with furniture on screen now gets a `MISSING-ACTION`
  error, because that shot was drawing the body at floor level. Add `"action": "sitOn"` /
  `"lieOn"` and `"on": "<prop type>"`, and declare the prop in that shot. There is no automatic
  migration: the correct `on` prop cannot be inferred safely.
- Anchors are only defined for chair, stool, bench, couch, bed, desk, table, vehicle seats and
  a few screens. Add a prop's anchors in `src/scene/anchors.ts` before using `action` with it.
